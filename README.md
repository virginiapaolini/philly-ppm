# elaborato ppm front-end #
-- replica del sito web del quotidiano The Philadelphia Inquirer ([https://www.inquirer.com/](http://www.philly.com/)).
-- è stato usato l'IDE JetBrains WebStorm
-- struttura delle cartelle:
                            philly-ppm 
                            |__index.html
                            |__css
                                |__style.css
                            |__javascript.js
-- il sito originale usa Tailwind + React perché ha molti banner: qui, per semplicità, è stato usato html+css e javascript per azioni interattive come search bar, menù a tendina eccetera.
-- gli svg del logo originale e delle icone sono stati riutilizzati
-- per immagini e testo è stato fatto uso di placeholders: https://placehold.co/ e https://www.lipsum.com/
